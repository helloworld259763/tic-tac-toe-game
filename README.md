# Aether Grid

Tic-tac-toe with a computer opponent (minimax), a "Vanishing" rule where each player keeps only three marks, and sound effects.

## Run locally

1. `npm install`
2. `npm run dev`

## Deploy on Vercel

Import the GitHub repository in Vercel. It is detected as a Vite project automatically (build command `npm run build`, output folder `dist`). No environment variables are needed.
